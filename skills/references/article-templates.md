# 文章模板

## 1. 活动回顾型（如龙虾局）

```
标题：当"[金句/梗]"，[活动名]聊了什么？

结构：
① 开场：时间地点氛围，一句话定基调
② 爆点：现场最有趣的瞬间（金句/梗/笑点）放最前
③ 活动内容：emoji 列表，简洁直接
④ 背景科普：新读者需要知道的上下文（可选）
⑤ 干货：2-5 个关键点，编号呈现，嵌进叙事
⑥ 感受：氛围收尾，情感共鸣
⑦ CTA：下期预告 / 关注 / 报名
```

**写作要点：**
- 梗/金句必须放第一屏
- 干货不超过 5 条，每条 2-3 行
- 数据具体化（"14天" 比 "两周" 更有力）
- 引用原话加引号，增加真实感

---

## 2. 产品介绍型

```
标题：[产品名] 能帮你做什么？

结构：
① 痛点开场：读者最头疼的问题
② 产品是什么：一句话定义
③ 核心功能：3-5 个，emoji 标注
④ 真实案例：具体数据支撑
⑤ 如何开始：操作步骤
⑥ CTA：下载 / 试用 / 关注
```

---

## 3. 干货分享型

```
标题：[数字] 个方法 / 关于 [话题] 你需要知道的

结构：
① 话题引入：为什么现在讲这个
② 干货主体：编号列表，每条有标题+解释+例子
③ 总结：一句话提炼
④ CTA
```
